# Промпт для Claude Code (скопируй всё ниже в чат Claude Code, открыв папку с распакованным архивом)

---

В этой папке лежит готовая онтология OWL для рекомендательной системы «Подбор оптимальной реабилитационной программы»
(вариант 22), SWRL-правила и 12 проверенных рекомендательных SPARQL-запросов. Сначала прочитай `CLAUDE.md`,
затем `docs/MODEL.md` и `scripts/check_queries.py`.

Задача: построй веб-приложение на **FastAPI + Jinja2** (Python 3.10+), строго по `CLAUDE.md`:

1. При старте загрузить `ontology/rehab_program.owl` в rdflib и применить `rules/materialize_rules.ru` до неподвижной точки.
2. Автоматически подхватить все запросы из `queries/recommend/*.rq` по их заголовкам (id, title, button, description,
   param, card) — без хардкода текстов запросов в Python.
3. Сделать JSON API из `CLAUDE.md` (stats, options, patients, catalog, queries, recommend) с безопасной подстановкой параметров.
4. Сделать страницы: главная (карточки-счётчики + карточки-кнопки 12 рекомендаций), пациенты (карточки с бейджами
   из SWRL-выводов), страница пациента (профиль + кнопки рекомендаций с подставленным пациентом, результаты карточками
   без перезагрузки), универсальная страница «Рекомендации» с формой параметров, каталог.
5. Интерфейс полностью на русском, адаптивный, карточки в стиле `reference/flask_example/static/style.css`.
6. Написать pytest-тесты из раздела «Тесты» в `CLAUDE.md` (сверка с `expected/expected_results.json`) и добиться,
   чтобы все проходили.
7. Добавить `requirements.txt` и `README_APP.md` с командами запуска.

Не меняй `ontology/`, `rules/`, `queries/`, `expected/` — это проверенная база знаний. Если чего-то не хватает,
скажи, а не переписывай запросы. В конце запусти `python3 scripts/check_queries.py`, `pytest -q` и сам сервер,
открой главную и страницу пациента «Новиков», нажми кнопки и убедись, что результаты совпадают с таблицей в `CLAUDE.md`.
